# Android 第三方许可

本项目使用以下第三方开源组件。完整许可文本以依赖包及其上游仓库随附内容为准。

| 组件 | 用途 | 许可证 |
| --- | --- | --- |
| AndroidX Core、Activity、Lifecycle、WebKit、Test | Android 平台兼容、生命周期、WebView 与测试 | Apache License 2.0 |
| Jetpack Compose、Material 3 | 声明式界面与 Material 组件 | Apache License 2.0 |
| AndroidX Room | 本地结构化数据存储 | Apache License 2.0 |
| Dagger Hilt | 依赖注入 | Apache License 2.0 |
| Jsoup | EPUB HTML 解析与清理 | MIT License |
| ICU4J | TXT 字符编码检测 | Unicode License V3 |

本项目的构建依赖还包括 Android Gradle Plugin、Kotlin、KSP、Gradle、JUnit 和 Espresso；其许可证与通知由各自发行包提供。发布者应在依赖升级时复核本清单及许可证义务。
