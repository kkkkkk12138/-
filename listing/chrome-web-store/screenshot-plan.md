# 小说一键换名商店截图脚本

## 目标

这组截图不是为了炫技，而是为了让用户在最短时间内看懂：

1. 这是一个阅读场景插件
2. 它在当前网页直接工作
3. 它尽量不改变原页面样式
4. 它配置很简单

## 截图顺序

建议准备 `4` 到 `5` 张截图，顺序如下。

## 截图 1

### 标题

在当前阅读网页里直接换名

### 要展示的内容

- 一个正常的小说或正文阅读网页
- 插件已经让主要角色名字替换完成
- 页面仍然像原网站一样自然

### 文案重点

- 不导出文本
- 不切换阅读器
- 直接在当前网页里生效

### 目的

第一张图只回答一个问题：`它到底是干什么的`

第二张图回答：`它难不难上手`

## 画面风格建议

- 尽量使用干净、阅读感强的页面做示例
- 截图里不要塞太多箭头和装饰文字
- 每张图只强调一个核心信息
- 不要把页面做成“营销海报”，而要像真实产品使用场景

## 建议拍摄方式

- 使用同一套浏览器主题和窗口尺寸
- 保持统一的缩放比例
- 只替换必要角色名，不要把一整页改得太花
- 优先展示正文，而不是浏览器外壳

## 推荐文案短句

这些短句适合覆盖在截图里，保持克制：

- 当前网页直接换名
- 点开就改，立即生效
- 尽量保持原样
- 动态内容继续生效
- 规则保存在本地

## 不推荐的截图文案

避免这些夸张表达：

- 全网一键改名神器
- 适配所有网站
- 永不出错
- AI 改写全页面

## 截图制作前的检查

- 扩展名称显示为 `小说一键换名`
- 浏览器工具栏中图标清晰可见
- 弹窗内容使用正式命名与正式文案
- 页面示例不要包含敏感或版权风险过高的私人内容
