# 小说一键换名权限与数据说明

## 这份说明的用途

这份文件用于：

- 回答 Chrome Web Store 审核时对权限的疑问
- 统一商店详情页、隐私政策和权限说明口径
- 帮助用户理解插件为什么申请这些权限

## 插件当前权限

### `storage`

用途：

- 在浏览器本地保存用户自己填写的替换规则

为什么必须要有：

- 如果没有本地存储，用户每次打开网页都要重新输入规则
- 这会显著破坏插件“打开就能继续用”的体验

当前处理方式：

- 规则默认保存到浏览器本地
- 当前版本不要求登录，不依赖云端同步

### `tabs`

用途：

- 识别当前活动标签页
- 把用户点击“立即生效”后的规则发送到当前页面

为什么必须要有：

- 插件的目标不是后台批量处理，而是让用户明确地把规则应用到“当前正在阅读的页面”
- 因此需要知道当前活动标签页是哪一个

当前处理方式：

- 插件只在用户主动点击后与当前页面通信
- 不把这个权限用于建立浏览行为画像

### `<all_urls>`

用途：

- 允许插件在用户主动打开的各类阅读网页中运行内容脚本

为什么必须要有：

- 小说、同人文和阅读网页来源分散，没有一个统一站点
- 如果只声明少量固定域名，插件会在大量真实阅读场景下直接失效

审核时的核心解释口径：

- `<all_urls>` 是为了“在任意用户主动打开的阅读网页中工作”
- 不是为了抓取全网数据，也不是为了建立跨站跟踪能力

## 数据使用原则

当前版本遵循以下原则：

- 只处理用户主动打开并主动使用插件的当前网页
- 规则默认保存在浏览器本地
- 不主动上传网页正文
- 不依赖账号体系
- 不以插件功能为前提建立远程用户数据库

## 审核说明推荐话术

如果需要在审核备注或补充说明里回答平台问题，可以优先使用下面这段：

> 本插件面向小说、同人文等阅读场景。`storage` 用于在本地保存用户自己配置的名字替换规则；`tabs` 用于识别当前活动标签页，并在用户点击“立即生效”后把规则应用到该页面；`<all_urls>` 用于让插件在用户主动打开的任意阅读网页中工作。当前版本不要求登录，不上传用户阅读正文，规则默认保存在浏览器本地。

## 用户可见说明推荐话术

如果需要在商店详情页中对普通用户解释权限，可以使用更易懂的版本：

> 这个插件需要读取当前网页，是因为它要在你正在阅读的页面里替换角色名字；它需要本地存储，是为了帮你记住替换规则。当前版本规则默认保存在浏览器本地，不需要账号，也不会主动上传网页正文。

## 高风险误解与修正方式

### 误解一：插件会读取所有网页内容

修正口径：

- 权限覆盖面广，是为了兼容不同阅读站点
- 实际处理发生在用户主动打开并使用插件的当前页面

### 误解二：插件会把全文传到服务器

修正口径：

- 当前版本不依赖账号，不需要把正文上传到远程端
- 规则和替换处理以本地浏览器环境为主

### 误解三：插件是通用网页改写器

修正口径：

- 当前主场景是小说、同人文等正文阅读网页
- 产品目标是帮助用户在原阅读环境里无感替换角色名字
