# 小说一键换名商店文案包

## 用途

这份文案用于填写 `Chrome Web Store` 的核心展示字段，也可以作为官网、介绍页或发布帖的基础文案底稿。

## 产品名称

小说一键换名

## 一句话定位

在当前阅读网页里直接替换角色名字，尽量不改变原网站的排版和样式。

## 短描述

打开网页即可替换小说、同人文里的角色名字。规则保存在本地，尽量保持原页面样式不变，不打断原有阅读习惯。

## 详细介绍

`小说一键换名` 是一个面向阅读场景的浏览器插件。它允许你在当前网页里直接把角色名字替换成你想看到的版本，而不要求你复制文本、切换阅读器，或重新整理内容。

它的核心目标不是“做一个复杂的文本处理器”，而是让你继续按照原来的方式阅读，只是在页面里看到更符合自己代入习惯的名字。  
无论你在看小说、同人文，还是其他以正文阅读为主的网页内容，都可以在插件弹窗里快速填写规则，然后立即对当前页面生效。

和许多会重建阅读层或注入大量样式的做法不同，`小说一键换名` 更强调“无感”。  
它会尽量直接作用于网页中的正文文本节点，避免额外包裹视觉层，以减少字体、字号、颜色和行高被改坏的概率。

## 适合谁

- 喜欢在阅读时替换主角名、CP 名或角色称呼的人
- 不想复制全文到其他工具里再处理的人
- 希望继续使用原网站、原阅读习惯的人
- 更重视“页面看起来还是原来的样子”的人

## 核心卖点

- 当前网页直接替换：不用导出文本，不用切换阅读器
- 尽量保持原样：优先保留原网站的字体、字号、颜色和排版风格
- 本地保存规则：常用替换规则会保存在浏览器本地
- 打开即用：点开插件，填好规则，立即对当前页面生效
- 适配动态页面：长页面、滚动加载或异步刷新的正文也会继续尝试生效

## 工作方式

1. 打开你正在阅读的网页
2. 点击浏览器工具栏里的 `小说一键换名`
3. 填写一条或多条 `原名 → 新名` 规则
4. 点击 `立即生效`
5. 当前页面正文会按规则替换

如果你只想临时在某一页使用，也可以关闭 `本页启用`，停止后续新增内容的继续替换。

## 功能边界

为了尽量减少误替换和视觉异常，当前版本默认更关注正文文本，而不是所有网页元素。  
输入框、按钮、代码块、预格式文本、可编辑区域等位置默认会被跳过。

同时也需要提前说明：

- 名字前后长度差异很大时，网页换行可能发生正常重排
- 某些特殊站点、`Shadow DOM`、图片文字、Canvas 内容不保证覆盖
- 当前版本以极简规则为主，不提供复杂站点级规则系统

## 用户信任表达

`小说一键换名` 当前版本不依赖账号系统，也不会主动把你正在阅读的网页正文上传到远程服务器。  
替换规则默认保存在浏览器本地，插件只在你主动打开网页并使用它时，对当前页面进行本地文本替换处理。

## 商店首屏推荐排布

建议在商店详情页前两屏优先传达这四点：

1. 它是阅读场景插件
2. 它在当前网页里直接工作
3. 它尽量保持原网站样式不变
4. 它把规则保存在本地，不要求导入全文

## 常见问题简答

### 这是给什么场景用的

适合小说、同人文和其他正文阅读网页，尤其适合想替换角色名字但不想改变原来阅读方式的人。

### 需要把文章复制出来吗

不需要。它直接在你正在打开的网页里工作。

### 会改坏原网站样式吗

插件会尽量直接处理正文文本节点，目标是尽量保持原网站样式不变，但极端页面结构下仍可能出现换行变化或个别不兼容情况。

### 规则会上传吗

当前版本规则默认保存在浏览器本地，不依赖账号系统，也不会主动上传网页正文。
